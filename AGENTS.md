# Оформление учебных отчётов

- Делать вывод кратким, одним предложением по цели работы. Пример: «Вывод: изучил динамическую маршрутизацию и настройку RIPv2».
- Сохранять пользовательские исправления в существующих отчётах.
- Использовать среднее тире «–» вместо длинного «—».
- Не использовать стрелки вроде «→» в тексте и подписях. Писать словами: «с PC2 на PC0», «в разделе Desktop открыть IP Configuration».
- Перед снятием скриншотов убирать указатель мыши за пределы снимаемого окна. Не добавлять снимки с видимым курсором или подсветкой курсора.
