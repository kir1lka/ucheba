Лабораторная работа №3. Spring Security

1. Откройте папку lab3 и запустите start-lab3.bat.
2. Дождитесь строки Started RaspisaApplication.
3. Откройте http://localhost:8083/login.
4. Для остановки приложения нажмите Ctrl+C в окне запуска.

Учебные учётные записи:
admin / Admin!2026 – вся панель
teacher / Teacher!2026 – журнал
student / Student!2026 – просмотр мероприятий
methodist / Methodist!2026 – управление мероприятиями

Для смены роли выйдите из аккаунта и войдите под другим логином.
Учётные записи создаются при первом запуске в отдельной базе data/raspisa-lab3.
Если порт занят, задайте SERVER_PORT перед запуском; по умолчанию используется 8083.
Готовый JAR требует Java 17. Для пересборки проекта также нужен Node.js.
Отчёт rep.ipynb можно загрузить в Google Colab; код в нём не выполняется.
