# Лабораторная работа 1

Семестр 2. Введение в Spring Boot. Проект Demo для хранения заметок.

## Запуск в PowerShell

```powershell
.\gradlew.bat bootRun
```

Адрес приложения: <http://localhost:8080>. Остановка: Ctrl+C.

## Сборка

```powershell
.\gradlew.bat bootJar
```

Используются JDK 17, Gradle Wrapper 8.12 и Spring Boot 3.2.3.
