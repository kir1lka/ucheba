# Проекты лабораторных на Gradle

Каждая лабораторная хранится в отдельной папке с полной копией проекта.

| Папка | Работа |
| --- | --- |
| `lab1` | Семестр 2, лабораторная 1, приложение Spring Boot для заметок |
| `lab2` | Семестр 2, лабораторная 2, список задач на Spring MVC и Thymeleaf |

Для следующих работ создаются папки `lab3`, `lab4` и далее. Если новая работа
продолжает предыдущую, в новую папку копируются исходники, настройки Gradle
и Gradle Wrapper. Папки `build`, `.gradle` и настройки IDE копировать не нужно.
Готовые предыдущие работы сохраняются.

## Запуск лабораторной 1

Откройте PowerShell в папке `lab1` и выполните:

```powershell
.\gradlew.bat bootRun
```

Откройте <http://localhost:8080>. Для остановки нажмите Ctrl+C.

Для сборки:

```powershell
.\gradlew.bat bootJar
```

Требуется JDK 17. Gradle скачивается автоматически через Wrapper.

В IntelliJ IDEA откройте папку `lab1` как Gradle-проект и выберите JDK 17.

## Запуск лабораторной 2

Откройте PowerShell в папке `lab2` и выполните `.\gradlew.bat bootRun`.
Приложение доступно по адресу <http://localhost:8081>.
Для сборки выполните `.\gradlew.bat bootJar`.
Каждая лабораторная имеет отдельные исходники и настройки Gradle.

Это самостоятельные копии проектов для запуска. Основной код и отчёты
находятся в [репозитории cad-2025](https://github.com/kir1lka/cad-2025/tree/main/sem2),
локально он подключён в `../мой репозиторий/cad-2025/sem2/labN`.
Перед коммитом изменения проекта нужно перенести в папку соответствующей
лабораторной в репозитории. Единственный отчёт оформляется как `rep.ipynb`
для просмотра в Google Colab: текст, блоки Java-кода и картинки в текстовых ячейках.
Выполняемые ячейки, установка зависимостей и запуск проекта в отчёт не добавляются.
Запуск и выполнение лабораторных остаются в отдельных Gradle-проектах.

Коммиты называются коротко, по-русски, без точки в конце и длинных тире,
например `сделал 1 лабу 2 семестр`. Перед пушем нужно перечислить изменения
и сообщить названия коммитов.
