# Лабораторная работа 2

Семестр 2. Spring MVC. Проект Demo для управления задачами.

## Запуск

Откройте PowerShell в этой папке:

```powershell
.\gradlew.bat bootRun
```

Откройте <http://localhost:8081>. Остановка приложения: Ctrl+C.

Используется порт 8081, чтобы первая и вторая лабораторные могли работать одновременно.

## Сборка

```powershell
.\gradlew.bat bootJar
```

Требуется JDK 17. Gradle 8.12 скачивается через Wrapper.

В IntelliJ IDEA откройте папку `lab2` как Gradle-проект и выберите JDK 17.

Реализованы добавление, просмотр, смена статуса и удаление задач.
Дополнительные задания: поиск, подтверждение удаления и оформление страницы.
Данные хранятся в памяти до остановки приложения.
