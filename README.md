## Лабораторные

**Готово** – выполнение подтверждено владельцем либо найдены собственные отчёты и материалы выполнения (предварительно до подтверждения). Сданные работы также считаются готовыми. **Сдано** – преподаватель принял работу, отмечается по сообщению владельца. `?` означает «пока нет данных», а не ноль. Методички, примеры преподавателя и пустые папки в готовые работы не входят.

## Как обновлять учёт

Достаточно написать в общем чате проекта, например:

- «Сделал Java №3» – добавить №3 в готовые, пересчитать остаток.
- «Сдал Web №1 и №2» – записать принятые номера и обновить счётчик сданных; готовых должно быть не меньше сданных.
- «По сетям №7 нужны исправления» – перенести работу в доработку и уточнить причину.
- «Курсовую по сетям защитил на 4» – отметить защиту и оценку.
- «Экзамен по Java 20 января» – добавить дату после уточнения года, если он неясен.

При каждом обновлении сохраняются ранее подтверждённые сдачи, номера работ и оценки. Если сообщена только часть сдач, записывается «не менее N: №…», а не делается вывод, что остальные не сданы. Если сообщено только количество, оно сохраняется без предположений о номерах сданных работ. При известных номерах общие числа пересчитываются по уникальным номерам; дата обновления меняется. Неизвестные данные остаются `?`.


## Работа с Web-проектами

Откройте нужный `index.html` из папки `web` в браузере. Установка зависимостей
и запуск сервера не требуются. Описание работ находится в [README Web-проекта](https://github.com/kir1lka/web-labs#readme).

Папка `web` сохраняет собственную историю коммитов. После обновления этого
подмодуля изменения сначала отправляются в `web-labs`, затем новая версия
подмодуля фиксируется в основном репозитории.

Экспорт переписки Telegram, временные файлы Word и материалы проверки отчётов
остаются локально и исключены из публикации через `.gitignore`.
