1. В этой папке выполнить: python lab_api.py
2. Открыть: http://127.0.0.1:8765/docs
3. Развернуть операцию, нажать Try it out, ввести параметры и нажать Execute.
4. Сохранить скриншоты Request URL, Server response и Response body.

Не запускать второй сервер, если сервер работы 7 уже работает на порту 8765.
Спецификация: http://127.0.0.1:8765/openapi.json
Swagger UI загружается с unpkg.com, поэтому нужен Интернет.
HTTP_результаты.json содержит фактические HTTP-проверки; запуск в Swagger UI отдельно не подтверждён.
