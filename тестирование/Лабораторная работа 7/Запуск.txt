1. В этой папке выполнить: python lab_api.py
2. Импортировать CRUD.postman_collection.json в Postman.
3. Выполнить коллекцию целиком: значение createdId заполняется автоматически.
4. Swagger UI: http://127.0.0.1:8765/docs

Порт 8765 должен быть свободен. Запускать только один экземпляр сервера для работ 7 и 8.
Сервер слушает только 127.0.0.1. Данные хранятся в памяти и сбрасываются при остановке.
Для Swagger UI нужен Интернет, так как его библиотека загружается с unpkg.com.

Newman_результаты.json: фактический прогон 15 запросов и 30 утверждений, 0 ошибок.
HTTP_результаты.json: отдельный фактический HTTP-прогон.
Публичный_API_результаты.json: HTTP-ответы JSONPlaceholder.
